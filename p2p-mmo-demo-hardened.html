원인 잡아서 수정했습니다. 문제는 연속 우클릭 때 **렌더링 위치는 이전 이동곡선의 현재 위치까지 진행했는데, 90ms 주기에 아직 안 실린 마지막 delta는 `predicted/event chain`에 반영되지 않은 채 새 이동이 시작되는 것**이었습니다. 즉 이런 식으로 누적됐습니다. ```text 렌더 위치: 105.4 마지막 기록 위치: 103.1 여기서 새 클릭 → 새 이동은 105.4에서 시작 → event chain은 103.1에서 시작 반복 → 최종 렌더 위치 ≠ 최종 논리 위치 ``` 이번 수정은 세 가지입니다. * **재이동 지정 직전** 현재 보간 위치까지 미전송 이동분을 즉시 move command로 flush * 새 이동 segment는 보간 좌표가 아니라 **flush 후 `getPredictedTail()` 좌표에서 시작** * 이동 종료 순간에도 마지막 delta를 반드시 flush한 뒤 `moveState` 제거 * 이동 중 사격도 렌더 좌표가 앞서지 않도록 먼저 movement flush 후 사격 origin 계산 즉 이제 로컬 렌더 위치와 event chain의 위치가 같은 기준선을 계속 유지합니다.
